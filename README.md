# Ücretsiz Sohbet Paneli

Node.js + Express + Socket.IO ile hazırlanmış başlangıç projesidir.

## Çalıştırma
1. Node.js 18+ kurulu olsun.
2. Terminalde proje klasöründe:
   `npm install`
3. Sonra:
   `npm start`
4. Tarayıcıdan `http://localhost:3000` aç.

## Admin
Demo admin adı: `admin`
Demo admin şifresi: `1234`

> Gerçek yayına almadan önce `.env` ile güçlü bir admin şifresi kullanın.
